# Annotated example edits (instruction examples for the image-comparison study)

Four street-view examples showing what counts as a good or a problematic edit.
Boxes: green = desirable change, orange = plausible but excessive change, red = undesirable change.
Model names and scores are intentionally omitted; panels are labelled Input Image, Edit 1, Edit 2.
None of these inputs appears in any of the comparison studies.

| File | Target attribute | Example |
|---|---|---|
| 01_beautiful_spanish_street.png | more beautiful | Edit 1 adds a stone facade and planters and keeps the street; Edit 2 re-renders sky, facades, balconies and plants |
| 02_lively_australian_street.png | more lively | Edit 1 turns the bare lot into a patio with seating; Edit 2 replaces the photo with an illustration |
| 03_safety_fairview_food_bank.png | safer | Edit 1 paints the curb; Edit 2 rebuilds the facade and adds people |
| 04_wealthy_portuguese_villa.png | wealthier | Edit 1 replaces the house and adds an expensive car |

## Descriptions

**01 Spanish street (beautiful).** Edit 1 improves the scene with a targeted change, a stone facade and two planters on one house, while the road, lamp, sign and sky stay exactly as they were. Edit 2 also makes the street prettier, but it does so by repainting the whole scene: new sky and lighting, climbing plants, a changed balcony and door, and added furniture, so the result no longer shows the same place with one intervention.

**02 Australian street (lively).** Edit 1 converts the bare dirt lot into a small paved patio with seating and planters, a change a council could actually build, and leaves the fence, houses and sky untouched. Edit 2 replaces the photograph with a painted illustration of a different neighbourhood, so nothing in it can be read as a change to this location.

**03 Food bank (safety).** Edit 1 makes one modest, realistic change, a painted curb, and keeps the building exactly as it is. Edit 2 adds street lighting, which is a reasonable safety intervention, but it also repaints the facade, adds windows, a new sign and planters, and inserts people and a dog, which changes the building and stages the scene rather than editing it.

**04 Portuguese villa (wealthy).** The edit swaps the original house for a glass-fronted modern villa and parks an expensive car in front, so the image looks wealthier only because it depicts a different property. Adding luxury objects such as a car is not an intervention a planner can make, and should be judged as a poor edit even though it looks polished.
